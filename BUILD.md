# Сборка .exe

## Как собрать

```powershell
.\build.ps1
```

На выходе:
- `dist\Player\` — портативная папка с `Player.exe`
- `Player-windows.zip` — архив для раздачи

Сборка занимает несколько минут. Нужны локальные `assets\`, `vlc_engine\`
и хотя бы один запуск из исходников (чтобы клиент Flet осел в `~/.flet/client`).

## Почему onedir, а не onefile

`--onefile` при **каждом** запуске распаковывает ~250 МБ (VLC + клиент Flet)
во временную папку — отсюда и двухминутный старт. `--onedir` не распаковывает
ничего: `Player.exe` стартует за пару секунд.

Дополнительно:
- клиент Flet лежит в `flet_client\` рядом с `.exe` и подключается через
  `FLET_VIEW_PATH` — иначе flet при первом запуске качает с GitHub ~96 МБ;
- UPX отключён — он замедляет старт и провоцирует ложные срабатывания антивирусов;
- из сборки вырезан веб-клиент Flet (`flet_web`, ~67 МБ) и лишние транзитивные
  пакеты (см. `excludes` в `player.spec`).

## Как раздать друзьям

Файл больше 100 МБ, в сам репозиторий его класть нельзя — только в **Releases**:

```bash
gh release create v1.0 Player-windows.zip -t "Плеер v1.0" -n "Распакуйте архив и запустите Player.exe"
```

Или вручную: GitHub → Releases → Draft a new release → перетащить `Player-windows.zip`.

## Что важно знать друзьям

- Распаковать **всю папку** целиком, `Player.exe` без соседних файлов не работает.
- Не запускать прямо из архива.
- SmartScreen ругнётся на неподписанный .exe: «Подробнее» → «Выполнить в любом случае».
- Свою музыку класть в папку `music` рядом с `.exe` (или поменять `start_path` в `config.txt`).
